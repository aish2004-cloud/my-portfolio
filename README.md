# 🚀 Aishwarya Ajabe — Personal Portfolio

A beautiful, responsive personal portfolio website for a Fullstack Developer.

🌐 **Live Site:** [aishwarya-ajabe.vercel.app](https://aishwarya-ajabe.vercel.app)

---

## ✨ Features

- Dark theme with animated gradient background
- Custom cursor with smooth follow effect
- Scroll-reveal animations
- Fully responsive (mobile + desktop)
- Sections: Hero, About, Skills, Projects, Contact

## 🛠️ Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Syne + DM Mono)
- Deployed on Vercel
